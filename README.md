# Amungsa Photo Studio

**Amungsa Photo Studio** adalah aplikasi web resmi pembuat dan editor foto berbasis template untuk Amungsa Cares Papua / Amungsa Foundation.

Aplikasi ini berjalan 100% *client-side* di browser menggunakan HTML5 Canvas, Vanilla CSS, dan JavaScript tanpa ketergantungan server atau database eksternal.

## ✨ Fitur Utama
- **4 Template Desain Resmi**:
  1. *Template 1 (Sinergi & Berita)*: Teks judul berita, badge kategori (font autentik OCRAExtended), dan kalender tanggal yang dapat disunting.
  2. *Template 2 (Dokumentasi Bersih)*: Tampilan foto penuh dengan watermark emblem biru resmi Amungsa.
  3. *Template 3 (Slogan Resmi)*: Grafis "Dari Piring Sehat, Lahir Masa Depan Hebat".
  4. *Template 4 (Kolase 3 Frame)*: Tiga frame melayang bertingkat.
- **Rasio Kanvas Fleksibel**:
  - Instagram Feed 4:5 (1080 &times; 1350 px)
  - Persegi 1:1 (1080 &times; 1080 px)
- **Ekspor Multi-Format**:
  - PNG HD (Kualitas tertinggi tanpa kompresi)
  - JPG (Standar Instagram Feed & hemat ukuran)
  - WebP (Modern, ringan, dan tajam)
- **Watermark & Logo Resmi**:
  - Emblem kubah biru Amungsa tanpa teks dengan slider transparansi penuh (5% - 100%).
  - Header logo proporsional dengan lingkaran kubah sempurna dan efek glow.
- **Kontrol Interaktif**:
  - Zoom & Pan foto di dalam template.
  - Zoom Preview HD (100% pixel-perfect).
  - Salin langsung ke Clipboard (*Ready to paste*).
